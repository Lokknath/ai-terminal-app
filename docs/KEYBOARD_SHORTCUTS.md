# Nexus Keyboard Shortcuts Reference

Nexus is engineered for keyboard-first developers. Below is the complete reference table of all shortcuts and operational scopes.

> **Note**: On Windows and Linux, substitute <kbd>⌘</kbd> (Command) with <kbd>Ctrl</kbd>.

---

## 🚀 Navigation & Mode Switching

| Shortcut | Action | Description | Scope |
| :--- | :--- | :--- | :--- |
| <kbd>⌘</kbd> + <kbd>K</kbd> | **Command Palette** | Open fast launcher to search commands, sessions, tools, and layouts | Global |
| <kbd>⌘</kbd> + <kbd>1</kbd> | **Code Workspace** | Switch to the primary multi-terminal coding grid | Global |
| <kbd>⌘</kbd> + <kbd>2</kbd> | **Agent Swarm** | Switch to the AI Agent Swarm telemetry center | Global |
| <kbd>⌘</kbd> + <kbd>3</kbd> | **AI Chat** | Switch to isolated web AI chat browser | Global |
| <kbd>⌘</kbd> + <kbd>4</kbd> | **API Studio** | Switch to cURL & Axios request builder | Global |
| <kbd>⌘</kbd> + <kbd>5</kbd> | **Notes** | Switch to the Markdown scratchpad | Global |
| <kbd>⌘</kbd> + <kbd>B</kbd> | **Toggle Sidebar** | Expand or collapse the left agent/navigation sidebar | Global |

---

## 🪟 Terminal Multiplexing & Layouts

| Shortcut | Action | Description | Scope |
| :--- | :--- | :--- | :--- |
| <kbd>⌘</kbd> + <kbd>T</kbd> | **New Terminal** | Open a new terminal session in the active folder | Global |
| <kbd>⌘</kbd> + <kbd>W</kbd> | **Close Active Pane** | Prompts verification dialog if an agent is active | Active Pane |
| <kbd>⌘</kbd> + <kbd>⇧</kbd> + <kbd>F</kbd> | **Toggle Fullscreen** | Maximize the active pane to 100% or restore layout | Active Pane |
| <kbd>⌘</kbd> + <kbd>]</kbd> | **Next Pane** | Shift focus to the next terminal in sequence | Global |
| <kbd>⌘</kbd> + <kbd>[</kbd> | **Previous Pane** | Shift focus to the previous terminal in sequence | Global |
| <kbd>⌘</kbd> + <kbd>+</kbd> | **Zoom In Font** | Increase terminal font size | Active Pane |
| <kbd>⌘</kbd> + <kbd>-</kbd> | **Zoom Out Font** | Decrease terminal font size | Active Pane |
| <kbd>⌘</kbd> + <kbd>0</kbd> | **Reset Font** | Reset terminal font size to default (13px) | Active Pane |

---

## 🤖 Swarm Orchestration & Attention Approvals

| Shortcut | Action | Description | Scope |
| :--- | :--- | :--- | :--- |
| <kbd>y</kbd> | **Approve Command** | 1-click execution approval for blocked agent commands | Active Waiting Pane |
| <kbd>n</kbd> | **Deny Command** | 1-click denial for blocked agent commands | Active Waiting Pane |
| <kbd>↑</kbd> / <kbd>↓</kbd> | **Navigate Swarm** | Move up and down the running agent list | Swarm Sidebar |
| <kbd>Space</kbd> / <kbd>Enter</kbd> | **Focus Agent** | Switch viewport directly to selected agent session | Swarm Sidebar |

---

## ⏱️ Top Header Developer Stopwatch

| Key / Gesture | Action | Description | Scope |
| :--- | :--- | :--- | :--- |
| <kbd>Click</kbd> | **Start / Pause** | Toggle stopwatch ticking state | Header Stopwatch |
| <kbd>Double-Click</kbd> | **Reset** | Instant reset elapsed time to `00:00` | Header Stopwatch |
| <kbd>Right-Click</kbd> | **Reset** | Context menu reset to `00:00` | Header Stopwatch |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | **Toggle** | Keyboard toggle when focused | Header Stopwatch |
| <kbd>Esc</kbd> / <kbd>Backspace</kbd> | **Reset** | Keyboard reset when focused | Header Stopwatch |
