### 🌟 Flagship Project: Nexus AI Terminal

> **Nexus** is an autonomous AI agent swarm workspace and terminal multiplexer. It features universal multi-account credential isolation (Gemini, Claude, Codex), real-time inter-terminal message piping via SpeakDock, 1-click execution approvals, dynamic font scaling, zero-drift developer stopwatch, and run-when-away system sleep prevention.
