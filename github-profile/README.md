> **Nexus** is an autonomous AI agent command center, resilient terminal multiplexer, and API studio built for engineers running multi-agent swarms alongside web research and microservices.

**Key Innovations in Nexus**:
- 🛡️ **Universal Credential Isolation**: Concurrent multi-account sandboxing for Gemini, Claude Code, and Codex without token collision.
- 🗣️ **Inter-Terminal SpeakDock**: Direct prompt piping, error trace handoffs, and buffer streaming between running terminals.
- ⏱️ **Zero-Drift Developer Stopwatch**: High-precision wall-clock stopwatch integrated into the header beside the IST clock.
- 🪟 **Resilient Multiplexing & Proportional Resizing**: 8-handle custom drag resizing with dynamic terminal font scaling that eliminates CLI line-wrap bugs.
- ☕ **Run-When-Away Sleep Guard**: PowerSaveBlocker integration keeping your machine awake while autonomous agents execute overnight.

👉 **Explore the repository:** [**Lokknath/ai-terminal-app**](https://github.com/Lokknath/ai-terminal-app)
